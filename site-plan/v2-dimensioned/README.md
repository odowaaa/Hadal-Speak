## How this differs from v1

- **Real dimensions.** Top edge = 14 m + 18 m = 32 m; right edge = 30.4 m + 4 m
  = 34.4 m; bottom edge = 30.5 m. These are drawn **to true scale** (16 px/m),
  not schematically.
- **Left edge length is genuinely unknown.** Only two local marks (3 m, 5 m)
  appear near the top of that run — they don't sum to the full edge. Per your
  direction, the left edge is drawn closing the shape at a proportional length
  (~34.4 m, matching the right edge) but is labelled **TBD** throughout — do
  not treat that closing length as a real measurement.
- **Three access points**, all explicitly labelled and blue-marked on this
  sketch: **Front Main Gate** (bottom edge), **Back Gate** (top edge, at the
  14 m/18 m break), **House back door and Gate** (right edge, at the 30.4 m/4 m
  break — shown as one combined feature, per its label). No "Emergency Door" is
  invented — this sketch doesn't label one.
- **Wall thickness (0.40 m) is drawn to true scale** this time (buffered
  polygon, not a schematic double-line), since we now have a real scale to
  work from.

## Explicit flags — please confirm before using for construction

1. **Possible unlabelled bend near the House back door/Gate.** The photo may
   show a slight inward jog in the wall there (where House MOG's compound
   meets Office MOG's), but no dimension defines it. I drew that run straight
   (same convention you confirmed for the top edge — a dimension-chain break
   is a gate, not necessarily a bend). If a real bend exists, tell me its
   offset and I'll correct the geometry.
2. **Front Main Gate stationing** along the 30.5 m run is a visual estimate
   (~35% in from the bottom-right corner), not a dimensioned position.
3. **Left edge total length** is TBD — the drawn ~34.4 m is indicative only.
4. **Building footprints** (Office MOG, House MOG) are schematic — position/
   orientation follow the sketch, but no dimensions were given, so sizes are
   approximate placeholders, clearly labelled TBD.
5. **True north** is not established from either reference — the drawing is
   oriented to match the sketch as drawn, flagged accordingly.

See the drawing's own **Dimension Register**, **Gate/Door Schedule**, and
**General Notes** for the complete, itemised list of what's confirmed vs. TBD.
